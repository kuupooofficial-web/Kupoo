KOUPOO — Make Space. Without Harm.
==================================

A single-page website for Koupoo, an early-stage Indian brand (Ahmedabad)
developing a humane, sound-based bird deterrent. The product is at CONCEPT
STAGE: all performance, range and price figures are R&D targets, not
verified claims.

FILES
-----
index.html   The complete website (HTML + CSS + JavaScript in one file).
README.txt   This file.

HOW TO VIEW
-----------
Open index.html in any modern browser (Chrome, Edge, Firefox, Safari).
No build step, server or installation is needed.

NOTE: Fonts (Instrument Serif, Manrope) load from Google Fonts. Offline,
the page still works using fallback fonts (Georgia / system sans-serif).

PAGE SECTIONS
-------------
Hero ........ Tagline and call to action
Problem ..... Why bird deterrence is needed
About ....... Vision, mission, affordability, humane design
How it works  Interactive demo of the sound-burst concept (bands B, C, D, E)
Range ....... Basic, Pro, Industrial, Max Industrial (click for spec sheets)
Why Koupoo .. Key benefits
Where ....... Homes, shops, warehouses, factories, airports, etc.
Future ...... R&D and planned features
Roadmap ..... Ahmedabad > Gujarat > India > International
Safety ...... What is NOT yet verified (honesty statement)
Contact ..... Email button

FEATURES
--------
- Responsive layout (mobile and desktop)
- Dark / light theme toggle (also follows system preference)
- Scroll-reveal animations
- Model specification pop-up windows

CUSTOMISING
-----------
1. Contact email: search index.html for "hello@koupoo.example" and
   replace it with your real address.
2. Prices and ranges: edit the Range section and the spec pop-up data
   in the <script> block near the end of the file.
3. Colours: edit the CSS variables at the top of the <style> block
   (--acc, --acc2, --bg, --ink).

DEPLOYING
---------
Upload index.html to any static host (GitHub Pages, Netlify, Vercel,
Cloudflare Pages, or ordinary web hosting). Because it is named
index.html, it will load automatically as the home page.

IMPORTANT BEFORE LAUNCH
-----------------------
- Replace the placeholder email address.
- Keep the "concept stage" disclaimers until deterrence performance,
  animal safety, human hearing safety and any ultrasonic claims have
  been verified by laboratory testing and certification.
